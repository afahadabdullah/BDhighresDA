# Updated-paper review and evidence recovery

Reviewed the current `manuscript/BDhighresDA_arxiv.tex` on 2026-10-01,
including every main result, figure caption, methods section and appendix.
The review concerns the model paper and the entire available test archive.
It does not expand the paper into the 2000–2025 historical-product study.

## Findings that affect the interpretation

1. **The station-level wins are supported.** The country-filtered station
   exports reproduce 113/132 strict wins against all five estimates and
   118/132, 128/132 and 131/132 wins against IMERG, CPC and CHIRPS. Median
   station correlations and RMSE gains are also recoverable. The new script
   writes `summary_crosschecks.json` with exact values and a source hash.
2. **Some main results still mix geographical samples.** Table 2's product
   pooled correlations, the heavy-rain table/figure, and the quoted paired
   CRPS intervals reuse the wider 133-station sample. Although some captions
   label this, those measurements do not establish Bangladesh-only intensity
   or significance claims. Replace them with the country rerun before making
   country-wide conclusions. Do not rescale correlations or confidence limits.
3. **The conclusion overstates the temporal comparison.** Section 4.4
   explicitly says all-product monthly/seasonal scores are pending, while
   the conclusion says those means are closer to gauges than any product.
   The available evidence establishes background-versus-analysis temporal
   improvement and sampled multi-year station-mean comparisons. It does not
   establish monthly/seasonal product superiority. WG2 must decide that result.
4. **Separate 2023 and 2024 results are missing.** Their combined country
   scores are recoverable by subtraction, but that does not prove improvement
   in each year separately. The new script exports daily results by every
   year and month, not only a selected year or the two complete seasons.
5. **The upstream-overlap argument is unmeasured.** No product-by-station,
   dated inventory establishes the size or even direction of a comparison
   “handicap.” The model also receives observation-derived information via
   CPC, CHIRPS and IMERG. Claims of guaranteed absence of verification-gauge
   information from SURMA-Flow, or that indirect information cannot explain a
   margin, need qualification. Local likelihood exclusion is established;
   upstream exclusion is not. WG4 reports confirmed identities, geographical
   candidates and unknown cases separately.
6. **“No observation enters training” is too broad.** BMD/BWDB reports and
   the assimilation-time IMERG observations are not direct training inputs,
   but CHIRPS targets and CPC predictors are observation-derived. State the
   direct-input distinction instead of claiming observation-free training.
   Gradient spreading and likelihood approximations also prevent an exact
   posterior claim; the exact flow–score algebra does not change that.
7. **Mechanisms remain hypotheses.** The two-arm comparison does not isolate
   causal effects of clustering, satellite support, error inflation or
   spreading. Lower temporal SD of an ensemble mean also does not, alone,
   establish that individual members fail to represent variability. Keep
   those explanations conditional until matched ablations/calibration scores
   support them.
8. **The figure/package workflow needs updating.** The current manuscript
   uses `fig01_overview` through `fig08_case`, generated by script 95. The old
   script-93 package manifest lists the previous script-91 figure family;
   it can omit figures required by the updated source. Use the corrected
   source-derived package inventory described below. Scientific conclusions
   still need author review after new values arrive.

The script records missing inputs rather than replacing them with assumed
values. The manuscript wording is left unchanged by the audit/recovery run.

## Run

Local inventory and recoverable summary crosschecks:

```bash
python scripts/96_complete_updated_paper_evidence.py
```

CPU saved-array evaluation on PRISM, from the repository root:

```bash
mkdir -p logs
sbatch slurm/cpcv2_updated_paper_evidence.sbatch
```

The launcher runs scripts 96, 90 and 92 over all four periods, with no model
inference, retraining or automatic job submission from Python. Its output is
`output/paper1_updated_evidence/`. Script 96 needs no production Zarr for the
primary gauge comparisons: it samples product fields from the validated
withheld NPZs and loads same-day CPC from the checkpoint-bound packed store.
It checks an available checkpoint/statistics file against the paper's pinned
hash. If content is unavailable, that identity remains unresolved.

Direct equivalent:

```bash
python scripts/96_complete_updated_paper_evidence.py \
  --run --run-existing \
  --root data/processed/v2_bmd_bwdb_superob_2021_2024 \
  --out-dir output/paper1_updated_evidence
```

Set `PAPER1_CPC_SOURCE` or pass `--cpc-source-zarr` if the archived packed
store path needs remapping. The source must contain original `cpc_precip`
and same-day date coordinates; lagged `condition` is never substituted.
`PAPER1_FULL_GRIDDED=1` additionally generates BD2 and full gridded diagnostics.
`PAPER1_HISTORY`, `PAPER1_SELECTION`, `PAPER1_COMPUTE` and
`PAPER1_UPSTREAM_INVENTORIES` forward actual optional inputs. A missing
manuscript source on HPC does not prevent scoring; its source hash is simply
unavailable there. Synchronize these updated public scripts, dependencies,
launcher and boundary snapshot before submitting.

Native IMERG: create a text file containing one actual prepared NetCDF path
per line, then set `PAPER1_NATIVE_IMERG_LIST=/path/to/list.txt` before `sbatch`.
Alternatively pass paths with `--native-imerg`. Files must cover the entire
requested archive and declare V07B, half-hourly source frequency, 24 hours
and accumulation end hour 03 UTC. Script 08 prepares this format from actual
half-hourly granules. Missing input granules must be acquired/prepared first;
script 96 does not download or replace them with the 0.4° assimilated field.

The native comparison rescored all six estimates on a separate finite
intersection. Its missingness cannot alter the primary five-way scores;
both sample sizes and attrition are exported. Missing grid neighbours are
not silently filled with zero rainfall. This may reduce counts relative to
older exports; any change must be stated in the paper.

## Upstream inventory schema

Pass `--upstream-inventories PATH.json` with *actual* provider inventories:

```json
{
  "inventories": [
    {
      "product": "cpc",
      "path": "actual_provider_station_membership.csv",
      "membership": "direct",
      "reference": "specific provider/version inventory source"
    }
  ]
}
```

These are schema examples, not existing data. Valid product keys are `cpc`,
`chirps`, `imerg`; membership is `direct` or `gauge_adjustment`. Paths are
relative to the JSON file. CSV columns are `station_id,start,end` and optional
`lat,lon,local_station_id,evidence`. Dates must document membership for the
evaluated product/version, not just the station's existence. A confirmed
local ID requires a documented `evidence` crosswalk. A location within 1 km
is only a candidate; date-incompatible records do not establish overlap.
Nonmatches stay unknown. A partial list, or merely a similar station name,
cannot prove non-use. Obtain the appropriate historical inventories from
providers; the script does not guess identities or assert a measured handicap.

## Job/provenance records and uncertainty

`--accounting-job-ids` reads explicit individual IDs with `sacct`, retaining
actual elapsed seconds, allocated resources, state, nodes and start/end times.
Raw allocation time is not automatically converted to model inference cost:
jobs can contain several arms or preparation stages. Use original logs or a
measured benchmark to supply the script-92 `--compute` schema in
`PAPER1_COMPLETION.md`. `--preparation-logs` scans original logs for executed
statistics paths but labels them as candidates; a current file or Slurm
default cannot prove historical statistics content. Missing historical
provenance remains unresolved.

WG3 resamples whole day blocks without crossing date gaps or the excluded
selection month. All stations on a day travel together. RMSE is recomputed
from resampled squared errors, not averaged from per-day RMSEs. Its gains
use pooled station-day weighting to match the product table, unlike P9's
equal-day CRPS estimator. Both 3- and 7-day sensitivities use 10,000 resamples
by default. CSVs contain pointwise 95% intervals and Bonferroni intervals
for the six primary product-by-metric contrasts for each block-width analysis.
They describe temporal uncertainty conditional on the fixed holdout, not
alternative networks, selection uncertainty or exhaustive cross-validation.
